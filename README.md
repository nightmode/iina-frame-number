# IINA Frame Number

An [IINA](https://github.com/iina/iina) plugin that can show the estimated frame number as a overlay in the bottom right corner of a video.

## Navigation

* [Install](#install)
* [Usage](#usage)
* [License](#license)

## Install

Create a zip file that includes all files and folders in this project.

Rename the extension of the file from `.zip` to `.iinaplgz`.

Open the innaplgz file and IINA should automatically install the plugin.

## Usage

Once the plugin is installed and enabled, use the IINA `Plugin` menu to show or hide the frame number overlay.

If the overlay is active, you can optionally click on the overlay to copy the currently displayed frame number to your clipboard.
